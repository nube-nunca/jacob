For Photo Uploads: upload photos in "photoassets > corresponding folders (architecture, events, portraits, etc.)". The photos will automatically appear in the corresponding filtered menu on the website.

For Video Uploads: Upload videos in "videoassets" folder, and specify its category, title, role, and blurb in the following file: "_data > videos.yml". You can click on the pencil shaped icon to 'edit this file' and fill in the information. The video file name in this yml file has to exactly match the video file you uploaded in the 'videoassets' folder.

For Instagram Post Uploads: go to "_pages > content.md" file and edit each project's information and Instagram URLs. You can find the URL by clicking on a specific instagram post and copying its URL. It should be a full-URL that looks like "https://www.instagram.com/p/UNIQUECODE" or "https://www.instagram.com/reels/UNIQUECODE".

For the main page looping video: upload a short video in "dist > assets" folder. Your video file's name has to be: featured.mp4
